# Men's Day

A small interactive surprise page for International Men's Day. Static HTML, CSS and JavaScript, no build step.

Flow: bouquet, headline and envelope letter, scrapbook collage, final surprise.

## Make it personal

Everything personal is in `config.js`: the letter, the notes, the title and the closing line.
To use real photos, put image files in an `assets/` folder and list them in `photos`.

## Run locally

`python3 -m http.server 4173` and open http://localhost:4173
