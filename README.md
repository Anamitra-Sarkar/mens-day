# Men's Day

A small interactive surprise page for International Men's Day. Static HTML, CSS and JavaScript, no build step.

Bilingual (Bengali default, English toggle). Flow: bouquet, headline and envelope letter, scrapbook collage, final surprise. On phones, tap the right half of the screen for next and the left half for back.

## Make it personal

Everything personal is in `config.js`: every word, in both languages (Bengali under `bn`, English under `en`).

## Run locally

`python3 -m http.server 4173` and open http://localhost:4173
