# Men's Day

A small interactive surprise page for International Men's Day. Static HTML, CSS and JavaScript, no build step.

English, with one line in Bengali. Flow: bouquet, headline and envelope letter, scrapbook collage, final surprise. On phones, tap the right half of the screen for next and the left half for back.

## Make it personal

Everything personal is in `config.js`: every word (English under `en`) plus the one Bengali line (`MENS_DAY_LINE`).

## Run locally

`python3 -m http.server 4173` and open http://localhost:4173
